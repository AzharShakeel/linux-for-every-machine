# Hacking Lab Commands Cheatsheet

Starter recon-and-maintenance commands for controlled security labs. This sheet is intentionally minimal and should be used only in authorized environments.

```bash
sudo apt update && sudo apt full-upgrade -y
ip a
nmap -sV <target-ip>
whois <domain>
nikto -h <target-url>
```

Only test systems you own or have explicit permission to assess.
